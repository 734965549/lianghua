## 同花顺 SDK

### 1. 股票/期货 SDK 的版本号、授权方式和调用语言绑定？ `[已确认-默认]`
- **结论（默认）**：阶段 6 骨架期无真实 SDK；`LIANGHUA_SDK_DRIVER=sim` 用 `SimulatedThsDriver` 验收映射，`native` 占位待文档填充。预计 Python 或 COM + `pywin32`。
- **可变更**：拿到真实 SDK 文档与授权后更新 `sdk-notes-stock.md` / `sdk-notes-futures.md`。

### 2. SDK 是否支持透传本地 `client_order_id`？ `[已确认-默认]`
- **结论（默认）**：**不支持**。适配层本地维护 `client_order_id ↔ sdk_order_id`；回调缺 `client_order_id` 时用 `sdk_order_id` 回查。
- **可变更**：若真实 SDK 支持透传，可简化 `ThsTradingAdapterBase` 映射表。

### 3. SDK 订单/成交回调是否稳定，是否需要单独线程或消息泵？ `[已确认-默认]`
- **结论（默认）**：采用**回调 + 轮询双通道**（订单 5s、资金/持仓 15s，见 scheduler）。
- **可变更**：SDK 文档若要求消息泵，在 `NativeThsDriver` 实现。

### 4. SDK 是否要求同花顺客户端保持登录或前台运行？ `[已确认-默认]`
- **结论（默认）**：**要求**。部署文档与健康检查提示保持客户端登录。
- **可变更**：以 SDK 官方说明为准。

### 5. 股票/期货撤单、平今、平昨字段如何表达？ `[已确认-默认]`
- **结论（默认）**：`action` + `metadata.offset`（`close_today` / `close_yesterday` / `close`）；期货套保 `metadata.hedge`。
- **可变更**：真实字段名在 `mapping.py` 与 sdk-notes 中更新。

### 6. SDK 查询接口是否有频率限制？ `[已确认-默认]`
- **结论（默认）**：假设有限制；保持现有 5s/15s 轮询，文档明确后可调。
- **可变更**：见 scheduler 间隔配置。

### 7. SDK 订单状态枚举完整列表？ `[已确认-默认]`
- **结论（默认）**：Simulated 驱动用样例码表；未知 → `unknown` + `system_events`。真实枚举到位后补 `mapping.py`。
- **可变更**：见 `sdk-notes-*.md` 状态对照表。

## 交易规则

### 1. 股票/期货首批允许交易的标的范围？ `[已确认-默认]`
- **结论（默认）**：MVP 少量标的验证，如股票 `600000.SH`、`600519.SH`，期货 `IF2409`、`rb2409`。白名单存 `risk_configs.allowed_symbols`。
- **可变更**：实盘前按账户权限调整白名单。

### 2. 是否允许市价单，还是 MVP 只允许限价单？ `[已确认-默认]`
- **结论（默认）**：**MVP 只允许限价单**；`price_type` 保留 `market`，风控默认可拒绝市价单。
- **可变更**：实盘前再评估。

### 3. 是否区分交易所时段、夜盘、节假日？ `[已确认-默认]`
- **结论（默认）**：区分；`risk_configs.trading_sessions` 配置日盘/夜盘，节假日 MVP 可手动维护。交易日历深化仍为后续增强。
- **可变更**：补全日历数据源后加强校验。

### 4. 当日亏损阈值按什么计算？ `[已确认-默认]`
- **结论（默认）**：按**当日权益峰值 - 当前权益**（日内最大回撤）；阈值 `risk_configs.daily_loss_limit`，默认 50000。
- **可变更**：用户可在风控设置页调整。

### 5. 熔断后是否默认自动撤销全部未成交委托？ `[已确认-默认]`
- **结论（默认）**：**是**，`auto_cancel_on_breaker = true`；`emergency-stop` 可显式传 `cancel_open_orders: false`。
- **已实现**：阶段 5。

### 6. 策略运行中是否允许人工撤单？ `[已确认-默认]`
- **结论（默认）**：**允许**，`/api/orders/{id}/cancel`，校验系统非停止状态，写审计日志。
- **已实现**：阶段 4。

## 数据与部署

### 1. PostgreSQL 本机安装还是 Docker？ `[已确认-默认]`
- **结论（默认）**：**本机安装优先**（EnterpriseDB）；亦支持 `docker compose`。见 `deployment-guide.md`。
- **已实现**：阶段 0 / 文档阶段 8。

### 2. 数据备份目录和频率？ `[已确认-默认]`
- **结论（默认）**：目录 `LIANGHUA_BACKUP_DIR`（默认 `./backups`）；MVP **手动** `backend/scripts/backup_db.ps1`；文件名 `lianghua_yyyyMMdd_HHmmss.sql.gz`。定时备份（如收盘后 16:00）留作后续。
- **已实现**：阶段 8 脚本落地。

### 3. 是否需要导入历史成交或历史行情作为初始数据？ `[已确认-默认]`
- **结论（默认）**：**不需要**。MVP 从启动日累积；历史导入脚本非 MVP。

### 4. 行情快照采样频率？ `[已确认-默认]`
- **结论（默认）**：行情驱动落库，同一标的默认 1 秒节流。
- **已实现**：阶段 2。

### 5. K 线由 SDK 提供还是系统自行聚合？ `[已确认-默认]`
- **结论（默认）**：优先 SDK `get_kline`；否则由 `market_snapshots` 聚合。Mock/sim 走适配器实现。
- **可变更**：真实 SDK 能力确认后固化。

## AI 复盘

### 1. 本地模型还是云端模型？ `[已确认-默认]`
- **结论（默认）**：先规则化模板（`model_name = rule_based`）；配置 `LIANGHUA_AI_PROVIDER=openai` 后接云端兼容接口。本地模型后续扩展。

### 2. 是否允许把交易数据发送到外部 AI 服务？ `[已确认-默认]`
- **结论（默认）**：**允许**发送聚合指标与必要明细，**不发送** SDK/账号密码。前端提示风险；可关 AI 走规则模板。

### 3. AI 报告导出 PDF 或 Markdown？ `[已确认-默认]`
- **结论（默认）**：MVP **Markdown**（复制）；PDF 后续。

### 4. AI 报告是否需要人工确认或标注？ `[已确认-默认]`
- **结论（默认）**：不强制确认；提供「有用/无用」写入 `ai_reports.metadata`。
